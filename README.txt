ATTRITION DASHBOARD (2026)

1. Double-click index.html (opens in Chrome / Edge / Firefox). Needs internet on first load for the chart and Excel libraries.
2. Pick Monthly / Quarterly / Half-Yearly / Yearly / Custom range, plus the Department, Zone and Grade filters.
3. Click any number to see the employees behind it. Every table, list and the top button has an Excel export.
4. To refresh with new data, click "Refresh with updated Excel" and choose the new file. It needs sheets named "Active" and "In Active".

Note: the dashboard contains employee names and IDs. Share it with care.
